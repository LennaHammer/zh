ti 计算器

金融计算器（BA II plus），科学计算器（ti 30），图形计算器（ti84），cas 计算器（ti 89，ti nspire cas）。

比如图形计算器经典的有 ti 84 plus。

我觉得最新的 ti nspire cx ii cas 操作有点繁琐。

## 函数清单

主要是 ti 84 plus，cas 参考 ti 89 / ti nspire。

按计算器自身菜单分类。CAS 独有函数单独一个子章节。
 

### **数字运算**

- abs(数值) : 绝对值 abs(-5)→5
- round(数值,位数) : 四舍五入 round(2.3456,2)→2.35
- int(数值) : 向下取整 int(-3.2)→-4
- iPart(数值) : 整数部分 iPart(-3.2)→-3
- fPart(数值) : 小数部分 fPart(-3.2)→-0.2
- min(列表或数值,数值) : 最小值
- max(列表或数值,数值) : 最大值
- gcd(a,b) : 最大公约数 gcd(12,18)→6
- lcm(a,b) : 最小公倍数 lcm(12,18)→36
- nCr(n,r) : 组合数,如 5nCr2→10
- nPr(n,r) : 排列数,如 5nPr2→20
- ! : 阶乘 5!→120
- √( : 平方根
- ^ : 幂 2^3→8
- log( / ln( : 常用对数 / 自然对数
- e^( / 10^( : 指数逆运算
- sin( / cos( / tan( : 三角(结果取决于 DEG/RAD 模式)
- sin⁻¹( / cos⁻¹( / tan⁻¹( : 反三角(2nd+SIN/COS/TAN,注意定义域)
- MODE→Radian/Degree : 弧度/角度模式,三角计算前先设对
- MATH→1:Frac (Ans→Frac) : 把小数转分数
- MATH→2:Dec (Ans→Dec) : 分数转小数

**TEST(2nd→TEST,逻辑)**
- = / ≠ / < / > / ≤ / ≥ : 比较,结果为 1(true)或 0(false)
- and / or / not : 逻辑与/或/非
- 例:5>3→1 ;条件判断时做 True/False 用

**ANGLE(MATH→ANGLE)**
- ° / ' / " : 度/分/秒(输入如 32°15'40")
- ▶DMS( ) : 小数角→度分秒
- ▶Deg / ▶Rad : 角度制/弧度制互相转换

**CMPLX(MATH→CMPLX,复数)**
- conj( ) / real( ) / imag( ) : 共轭 / 实部 / 虚部
- abs( ) : 模,如 abs(3+4i)→5
- ▶Rect / ▶Polar : 直角坐标⇄极坐标

**BASE(2nd→MATH→BASE,进制)**
- 输入 / 输出: bin(二)、oct(八)、dec(十)、hex(十六)
- 例:bin→hex 转换,以及位运算
- 需先把计算器设为 BASE 模式(2nd→MATH→BASE)

**解方程(仅数值,无符号)**
- MATH→0:solver( : 数值解方程
- MATH→Poly : PolySolver( : 数值求多项式根

注:TI-84 只能给出数值近似答案,不能做符号运算;符号解在 CAS 节。

### **矩阵**

- 2nd→MATRIX→1:Edit : 编辑矩阵,先设行/列数再逐个输数值
- 输入用方括号: `[[1,2],[3,4]]`
- MATRIX→MATH→det(A) : 行列式
- A^-1 : 逆矩阵(求逆)
- A\*B / A^n : 矩阵乘法 / 幂
- MATRIX→MATH→rref(A) : 化为行最简形(解线性方程组)
- MATRIX→MATH→ref(A) : 行阶梯形
- MATRIX→MATH→transpose(A) : 转置
- MATRIX→MATH→identity(n) : n 阶单位阵
- MATRIX→MATH→rowSwap( / row+( / *row( / *row+( : 初等行变换

### **微积分**（数值）

- nDeriv(f(x),x,点) : 数值导数,如 nDeriv(x²,x,3)→6
- fnInt(f(x),x,a,b) : 数值定积分,如 fnInt(x²,x,0,1)→0.333...
- dy/dx : 图形界面求切线斜率(Calc→dy/dx)
- ∫f(x)dx : 图形界面求面积(Calc→∫f(x)dx)

符号微积分在 CAS。
### **统计**

STAT 菜单分四块:Edit / Calc / List / Tests。

**STAT→Edit**
- 数据输入 : 输入到 L1/L2(STAT→1:Edit)

**STAT→Calc**
- 1-Var Stats L1 : 单变量统计(x̄、Σx、Σx²、Sx 样本σ、σx 总体σ、minX、Q1、Med、Q3、maxX)
- 2-Var Stats L1,L2 : 双变量统计(x̄、ȳ、r)
- 回归:LinReg(ax+b)、QuadReg、CubicReg、QuartReg、ExpReg、LnReg、PowerReg、Logistic、MedMed
- 把回归结果存到 Y= 需 YVar 参数,如 LinReg(ax+b) L1,L2,Y1

**STAT→List(列表运算,LIST→MATH)**
- 描述统计: mean( / median( / stdDev( / variance( / sum( / min( / max( 都要基于列表
- SortA(列表) / SortD(列表) : 升序 / 降序排序

**STAT→Tests(推断)**

检验
- Z-Test(μ0, σ, x̄, n) 或 Z-Test(μ0, σ, List) : 已知 σ 的单总体均值检验
- T-Test(μ0, x̄, s, n 或 List) : 未知 σ 的单总体均值检验
- 2-SampZTest(x̄1, σ1, n1, x̄2, σ2, n2) 或 2-SampZTest(List1, List2) : 已知 σ 的两总体均值比较
- 2-SampTTest(x̄1, s1, n1, x̄2, s2, n2) 或 2-SampTTest(List1, List2) : 未知 σ 的两总体均值比较
- 1-PropZTest(p0, x, n) : 单总体比例检验
- 2-PropZTest(x1, n1, x2, n2) : 两总体比例比较
- Chi2-Test(观测矩阵) : 两分类变量独立性(卡方)
- Chi2-GOF-Test(观测列表, 期望列表) : 拟合优度(卡方)
- ANOVA(多组列表) : 单因素方差分析
- 2-SampFTest(s1, n1, s2, n2) 或 2-SampFTest(List1, List2) : 两总体方差比较
- LinRegTTest(x列表, y列表) : 线性回归斜率/相关检验
置信区间
- ZInterval(σ, x̄, n) 或 ZInterval(σ, List) : 已知 σ 的单均值区间
- TInterval(x̄, s, n) 或 TInterval(List) : 未知 σ 的单均值区间
- 2-SampZInt(σ1, σ2, x̄1, n1, x̄2, n2) 或 2-SampZInt(List1, List2) : 已知 σ 的两均值差区间
- 2-SampTInt(x̄1, s1, n1, x̄2, s2, n2) 或 2-SampTInt(List1, List2) : 未知 σ 的两均值差区间
- 1-PropZInt(x, n) : 单比例区间
- 2-PropZInt(x1, n1, x2, n2) : 两比例差区间
- LinRegTInt(x列表, y列表) : 回归系数区间

**DISTR(2nd→VARS,概率分布)**
- normalpdf(x, μ, σ) / normalcdf(下, 上, μ, σ) : 正态密度 / 区间概率
- invNorm(面积, μ, σ) : 正态反查分位数(z 或 x)
- tpdf( / tcdf( / invT( : t 分布密度 / 概率 / 分位数
- χ²pdf( / χ²cdf( : 卡方密度 / 概率
- Fpdf( / Fcdf( : F 分布密度 / 概率
- binompdf(n, p, k) / binomcdf(n, p, k) : 二项分布(单点 / ≤k)
- poissonpdf(μ, k) / poissoncdf(μ, k) : 泊松分布
- DISTR→DRAW→ShadeNormal( 等 : 图上涂色显示区间面积

用法:输入数据或统计量→选 Tail(≠/< />)→Calculate 出 p 值

### **画图**

- Y= : 输入要画的函数(如 Y1=sin(x))
- Window : 设置 Xmin/Xmax/Ymin/Ymax(或 Xscl/Yscl 刻度)
- Zoom → ZStandard : 恢复标准窗口(默认 -10..10)
- Zoom → ZoomFit : 自动适配 Y 范围
- Zoom → ZoomIn/Out : 以光标为中心放大/缩小
- Trace : 光标沿曲线移动,读 x/y 值
- Calc → minimum / maximum : 找极值点
- Calc → zero : 找零点(曲线与 x 轴交点)
- Calc → intersect : 找两条曲线交点(需 2 条 Y)
- 2nd→Table : 显示函数数值表,可改 ΔTbl
- 2nd→STAT PLOT : 画散点/直方图(配 L1、L2 数据)

### **CAS**

注意 TI-84 没有 CAS 功能，补充 ti 89 的 cas 函数。

 **数字运算**

- exact(表达式) : 保留符号/分数答案,如 exact(1/3)→1/3、exact(√2)→√2
- approx(表达式) : 强制转小数,如 approx(1/3)→0.333…;也可按 Ctrl+Enter 出小数近似(默认 Enter 走符号优先)

 **代数(符号计算)**

- solve(方程,变量) : 符号解方程 solve(x²-4=0,x)→x=2 or x=-2
- zeros(表达式,变量) : 符号求零点 zeros(x²-4,x)→2,-2
- factor(表达式) : 因式分解 factor(x²-1)→(x-1)(x+1)
- expand(表达式) : 展开 expand((x+1)²)→x²+2x+1
- comDenom(表达式) : 通分合并为一个分数
- propFrac(表达式) : 转为带余式(假分数→真分数)
- suchThat : 给解附加约束条件,只取满足条件的解,如 solve(x²=a,x,suchThat(a>0))→x=√a(仅 a≥0 时);作用等同 `|`(with)运算符,如 solve(x=√y,x)|y>0 (nSpire 专属,TI-89 用 | 运算符)
- combine(表达式) : 把对数/三角合并,如 combine(ln(x)+ln(y))→ln(x·y)、combine(sin(x)cos(x))→sin(2x)/2 (nSpire 专属,TI-89 用 tcollect)
- completeSquare(表达式,变量) : 配方法(化为顶点式),如 completeSquare(x²+6x+1,x)→(x+3)²-8、completeSquare(x²-4x+5,x)→(x-2)²+1;二次函数求顶点/最值很好用 (nSpire 专属,TI-89 无)
- simplify(表达式) : 化简
- C/= : 不相等假设(tilde 约束)

 **微积分**

- derivative(表达式,变量) : 符号求导 d/dx(x³)→3x²
- integral(表达式,变量) : 符号不定积分 ∫ x² dx→x³/3
- integral(表达式,变量,a,b) : 符号定积分 ∫₀¹x² dx→1/3
- nInt(表达式,变量,a,b) : 数值定积分(CAS 界面不支持符号时用)
- limit(表达式,变量,点) : 极限 limit(sin(x)/x,x,0)→1
- sum(序列) : 符号求和 sum(1/i,i,1,n)
- product(序列) / Π : 符号求积

 **统计**

- Data & Statistics 应用 : nSpire 的探索式图表环境,把列表变量拖到坐标轴即可自动生成散点图/直方图/箱线图/正态概率图;点图上数据点还可联动回列表,适合快速看数据分布 (nSpire 专属,TI-89 无)

 

### 金融 

主要是 TI BA II Plus，也包括 ti 84 的金融函数。
独立机型。用工作表(worksheet)操作:`2nd`+对应键打开,↑/↓ 切字段,ENTER 确认,CPT 计算。先用 `2nd→FORMAT` 设小数位(如 DEC=2)。现金流符号约定:支出记负、收入记正。

**TVM(时间价值)**
- 顶行键 N / I/Y / PV / PMT / FV : 输入数值或求未知
- CPT : 求对应的未知量,如输入 N、I/Y、PV、FV 后 CPT→PMT 求每期付款
- P/Y、C/Y(2nd→P/Y) : 每年付款次数 / 复利次数
- 2nd→CLR TVM : 清空 TVM 数据
- 2nd→BGN : 期初(annuity due)/期末(ordinary)年金,END 为默认

**现金流(CF)**
- 2nd→CF : 输入 CF0、C01、F01、C02、F02…
- NPV : 净现值(给定利率)
- IRR : 内部收益率

**摊销(AMORT)**
- 2nd→AMORT : 定 P1/P2 期区间 → BAL 余额、PRN 本金、INT 利息

**统计 & 回归**
- 2nd→DATA : 输入 X/Y 数据
- 2nd→STAT : x̄、s、σx、Σx、Σx²、Σxy、r、回归斜率/截距
- 回归模型: LIN / LOG / EXP / PWR(统计屏里选)

**日期 / 债券 / 折旧**
- 2nd→DATE : DBD 两日期间的天数、日期计算
- 2nd→BOND : 债券价格 / 收益率
- 2nd→DEPR : 折旧 SL(直线)/ SYD(年数合计)/ DB(余额递减)/ DBX

**利率与换算**
- 2nd→ICONV : NOM(名义)⇄EFF(实际有效) 利率互转
- %CHG : 百分比变化
- COST / SELL / MARGIN : 成本 / 售价 / 利润率三者换算
- 2nd→Math : 分数↔小数
- 内存寄存器 : STO→0-9 存, RCL→取;可在任何工作表间复用数值
