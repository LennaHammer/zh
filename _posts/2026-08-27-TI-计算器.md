金融计算器（BA II plus），科学计算器（ti 30），图形计算器（ti84），cas 计算器（ti 89，ti nspire cas）。

比如图形计算器经典的有 ti 84 plus。

我觉得最新的 ti nspire cx ii cas 操作有点繁琐。

## 函数清单

主要是 ti 84 plus，cas 参考 ti 89 / ti nspire。

按计算器自身菜单分类。CAS 独有函数单独一个子章节。

2nd 功能:直接写键上方黄色标注(如 TEST、ANGLE、DISTR);MATH 二级菜单写 MATH→NUM / PRB / CMPLX / BASE。

### **数字运算**

**MATH→NUM**
- abs(数值) : 绝对值 abs(-5)→5
- round(数值,位数) : 四舍五入 round(2.3456,2)→2.35
- int(数值) : 向下取整 int(-3.2)→-4
- iPart(数值) : 整数部分 iPart(-3.2)→-3
- fPart(数值) : 小数部分 fPart(-3.2)→-0.2
- min(列表或数值,数值) : 最小值
- max(列表或数值,数值) : 最大值
- gcd(a,b) : 最大公约数 gcd(12,18)→6
- lcm(a,b) : 最小公倍数 lcm(12,18)→36

**MATH→PRB**
- nCr(n,r) : 组合数,如 5nCr2→10
- nPr(n,r) : 排列数,如 5nPr2→20
- ! : 阶乘 5!→120
- rand / randInt(最小,最大) / randNorm(μ,σ) : 随机数

**直接键**
- √(数值) : 平方根
- ^ : 幂 2^3→8
- log(数值) / ln(数值) : 常用对数 / 自然对数
- e^(数值) / 10^(数值) : 指数函数(ln / log 的反函数)
- sin(数值) / cos(数值) / tan(数值) : 三角(结果取决于 DEG/RAD 模式)
- sin⁻¹(数值) / cos⁻¹(数值) / tan⁻¹(数值) : 反三角(对应键上方黄字,注意定义域)
- MODE→Radian/Degree : 弧度/角度模式,三角计算前先设对
- MATH→1:Frac (Ans→Frac) : 把小数转分数
- MATH→2:Dec (Ans→Dec) : 分数转小数

**TEST(逻辑)**
- = / ≠ / < / > / ≤ / ≥ : 比较,结果为 1(true)或 0(false)
- and / or / not : 逻辑与/或/非
- 例:5>3→1 ;条件判断时做 True/False 用

**ANGLE(角度)**
- ° / ' / " : 度/分/秒(输入如 32°15'40")
- ▶DMS(数值) : 小数角→度分秒
- ▶Deg / ▶Rad : 角度制/弧度制互相转换

**MATH→CMPLX(复数)**
- conj(复数) / real(复数) / imag(复数) : 共轭 / 实部 / 虚部
- abs(复数) : 模,如 abs(3+4i)→5
- ▶Rect / ▶Polar : 直角坐标⇄极坐标

**MATH→BASE(进制)**
- 输入 / 输出: bin(二)、oct(八)、dec(十)、hex(十六)
- 例:bin→hex 转换,以及位运算
- 需先进入 BASE 菜单:按 2nd+MATH 后切到 BASE

### **解方程(数值)**

- MATH→B:Solver... : 数值求解器界面,输入方程后按 ALPHA+SOLVE,一次求一个解
- 多项式求根:需第三方 App(PlySmlt2)或 CAS 机型 zeros(多项式,变量) / polyRoots(多项式,变量)

注:TI-84 只能给出数值近似答案,不能做符号运算;符号解在 CAS 节。

### **矩阵**

- MATRIX→1:Edit : 编辑矩阵,先设行/列数再逐个输数值
- 输入用方括号: `[[1,2],[3,4]]`

MATRIX→MATH
- det(A) : 行列式
- A^-1 : 逆矩阵(求逆)
- A\*B / A^n : 矩阵乘法 / 幂
- rref(A) : 化为行最简形(解线性方程组)
- ref(A) : 行阶梯形
- transpose(A) : 转置
- identity(n) : n 阶单位阵
- rowSwap(矩阵,行1,行2) / row+(矩阵,行1,行2) / *row(倍数,矩阵,行) / *row+(倍数,矩阵,行1,行2) : 初等行变换

### **微积分**（数值）

- nDeriv(f(x),x,点) : 数值导数(MATH→nDeriv),如 nDeriv(x²,x,3)→6
- fnInt(f(x),x,a,b) : 数值定积分(MATH→fnInt),如 fnInt(x²,x,0,1)→0.333...
- dy/dx : 图形界面求切线斜率(Calc→dy/dx)
- ∫f(x)dx : 图形界面求面积(Calc→∫f(x)dx)

符号微积分在 CAS。

### **统计**

STAT 菜单:Edit / Calc / Tests 三块;列表运算在 LIST(STAT 键上方黄字)。

**STAT→Edit**
- 数据输入 : 输入到 L1/L2(STAT→1:Edit)

**STAT→Calc**
- 1-Var Stats L1 : 单变量统计(x̄、Σx、Σx²、Sx 样本σ、σx 总体σ、minX、Q1、Med、Q3、maxX)
- 2-Var Stats L1,L2 : 双变量统计(x̄、ȳ、r)
- 回归:LinReg(ax+b)、QuadReg、CubicReg、QuartReg、ExpReg、LnReg、PowerReg、Logistic、MedMed(显示 r/r² 需先 CATALOG→DiagnosticsOn)
- 把回归结果存到 Y= 需 YVar 参数,如 LinReg(ax+b) L1,L2,Y1

**LIST(列表运算)**
- LIST→MATH: mean(列表) / median(列表) / stdDev(列表) / variance(列表) / sum(列表) / min(列表) / max(列表) 都要基于列表
- SortA(列表) / SortD(列表) : 升序 / 降序排序(STAT→OPS)

**STAT→Tests(推断)**

用法:先选 Input(Data 用原始列表 / Stats 用统计量),再选 Tail(≠ / < / >)→Calculate 出 p 值;区间则在 C-Level 输置信水平。列表输入可加 Freq 频数。

**检验**
- Z-Test(μ0, σ, x̄, n) 或 Z-Test(μ0, σ, List) : 单总体均值检验(σ 已知)，判断均值是否等于 μ0,如均值是否达标
- T-Test(μ0, x̄, s, n) 或 T-Test(μ0, List) : 单总体均值检验(σ 未知,用样本 s)，小样本时判断均值是否等于 μ0
- 2-SampZTest(x̄1, σ1, n1, x̄2, σ2, n2) 或 2-SampZTest(List1, List2) : 两总体均值比较(σ 已知)，判断两总体均值是否相等
- 2-SampTTest(x̄1, s1, n1, x̄2, s2, n2) 或 2-SampTTest(List1, List2) : 两总体均值比较(σ 未知)，判断两组处理效果是否有差异(可选 Pooled:Yes/No)
- 1-PropZTest(p0, x, n) : 单总体比例检验(x=成功次数)，判断比例是否等于/高于/低于 p0,如合格率是否达标
- 2-PropZTest(x1, n1, x2, n2) : 两总体比例比较，判断 A/B 两组比例是否不同
- Chi2-Test(观测矩阵) : 卡方独立性/同质性检验(列联表)，判断两分类变量是否独立;观测频数矩阵先存到 [A],期望矩阵由计算器算出
- Chi2-GOF-Test(观测列表, 期望列表) : 卡方拟合优度检验，判断样本是否服从某理论分布,如骰子是否均匀
- ANOVA(多组列表) : 单因素方差分析(≥2 组)，判断多组均值是否相同
- 2-SampFTest(s1, n1, s2, n2) 或 2-SampFTest(List1, List2) : 两总体方差比较，判断两总体方差是否不同
- LinRegTTest(x列表, y列表) : 线性回归显著性检验，判断 x、y 是否有显著线性关系(H0: β=0、ρ=0)

**置信区间**
- ZInterval(σ, x̄, n) 或 ZInterval(σ, List) : 单总体均值区间(σ 已知)，估计均值的置信范围,如 95% 下均值所在区间
- TInterval(x̄, s, n) 或 TInterval(List) : 单总体均值区间(σ 未知,小样本)，估计均值的置信范围
- 2-SampZInt(σ1, σ2, x̄1, n1, x̄2, n2) 或 2-SampZInt(List1, List2) : 两均值差区间(σ 已知)，估计两总体均值差的范围
- 2-SampTInt(x̄1, s1, n1, x̄2, s2, n2) 或 2-SampTInt(List1, List2) : 两均值差区间(σ 未知)，估计两总体均值差的范围
- 1-PropZInt(x, n) : 单比例区间，估计单总体比例的置信范围,如合格率的置信区间
- 2-PropZInt(x1, n1, x2, n2) : 两比例差区间，估计两总体比例差的范围
- LinRegTInt(x列表, y列表) : 回归系数区间，估计回归斜率 β 的范围,看线性关系强度

**DISTR(概率分布)**
- normalpdf(x, μ, σ) / normalcdf(下, 上, μ, σ) : 正态密度 / 区间概率
- invNorm(面积, μ, σ) : 正态反查分位数(z 或 x)
- tpdf(x,df) / tcdf(下,上,df) / invT(面积,df) : t 分布密度 / 概率 / 分位数
- χ²pdf(x,df) / χ²cdf(下,上,df) : 卡方密度 / 概率
- Fpdf(x,df1,df2) / Fcdf(下,上,df1,df2) : F 分布密度 / 概率
- binompdf(n, p, k) / binomcdf(n, p, k) : 二项分布(单点 / ≤k)
- poissonpdf(μ, k) / poissoncdf(μ, k) : 泊松分布
- DISTR→DRAW→ShadeNormal(下,上,μ,σ) 等 : 图上涂色显示区间面积

### **画图**

- Y= : 输入要画的函数(如 Y1=sin(x))
- Window : 设置 Xmin/Xmax/Ymin/Ymax(或 Xscl/Yscl 刻度)
- Zoom → ZStandard : 恢复标准窗口(默认 -10..10)
- Zoom → ZoomFit : 自动适配 Y 范围
- Zoom → ZoomIn/Out : 以光标为中心放大/缩小
- Trace : 光标沿曲线移动,读 x/y 值
- Calc → minimum / maximum : 找极值点
- Calc → zero : 找零点(曲线与 x 轴交点)
- Calc → intersect : 找两条曲线交点(需 2 条 Y)
- Table : 显示函数数值表,可改 ΔTbl
- STAT PLOT : 画散点/直方图(配 L1、L2 数据)

### **CAS**

注意 TI-84 没有 CAS 功能，补充 ti 89 的 cas 函数。

**数字运算**

- exact(表达式) : 保留符号/分数答案,如 exact(1/3)→1/3、exact(√2)→√2
- approx(表达式) : 强制转小数,如 approx(1/3)→0.333…;也可按 Ctrl+Enter 出小数近似(默认 Enter 走符号优先)

**代数(符号计算)**

- solve(方程,变量) : 符号解方程 solve(x²-4=0,x)→x=2 or x=-2
- zeros(表达式,变量) : 符号求零点 zeros(x²-4,x)→2,-2
- factor(表达式) : 因式分解 factor(x²-1)→(x-1)(x+1)
- expand(表达式) : 展开 expand((x+1)²)→x²+2x+1
- comDenom(表达式) : 通分合并为一个分数
- propFrac(表达式) : 转为带余式(假分数→真分数)
- suchThat : 给解附加约束条件,只取满足条件的解,如 solve(x²=a,x,suchThat(a>0))→x=√a(仅 a≥0 时);作用等同 `|`(with)运算符,如 solve(x²=y,x)|y>0 (nSpire 专属,TI-89 用 | 运算符)
- combine(表达式) : 把对数/三角合并,如 combine(ln(x)+ln(y))→ln(x·y)、combine(sin(x)cos(x))→sin(2x)/2 (nSpire 专属,TI-89 用 tcollect)
- completeSquare(表达式,变量) : 配方法(化为顶点式),如 completeSquare(x²+6x+1,x)→(x+3)²-8、completeSquare(x²-4x+5,x)→(x-2)²+1;二次函数求顶点/最值很好用 (nSpire 专属,TI-89 无)
- simplify(表达式) : 化简

**微积分**(TI-89 写作 d(表达式,变量) / ∫(表达式,变量),其余同名)

- derivative(表达式,变量) : 符号求导 d/dx(x³)→3x²
- integral(表达式,变量) : 符号不定积分 ∫ x² dx→x³/3
- integral(表达式,变量,a,b) : 符号定积分 ∫₀¹x² dx→1/3
- nInt(表达式,变量,a,b) : 数值定积分(CAS 界面不支持符号时用)
- limit(表达式,变量,点) : 极限 limit(sin(x)/x,x,0)→1
- sum(序列) : 符号求和 sum(1/i,i,1,n)
- product(序列) / Π : 符号求积

**统计**

- Data & Statistics 应用 : nSpire 的探索式图表环境,把列表变量拖到坐标轴即可自动生成散点图/直方图/箱线图/正态概率图;点图上数据点还可联动回列表,适合快速看数据分布 (nSpire 专属,TI-89 无)

### 金融

主要是 TI BA II Plus，也包括 ti 84 的金融函数。

独立机型。用工作表(worksheet)操作:2nd+键上方黄字标注打开,下文直接写标注名,↑/↓ 切字段,ENTER 确认,CPT 计算。先用 FORMAT 设小数位(如 DEC=2)。现金流符号约定:支出记负、收入记正。

**TVM(时间价值)**
- 顶行键 N / I/Y / PV / PMT / FV : 输入数值或求未知
- CPT : 求对应的未知量,如输入 N、I/Y、PV、FV 后 CPT→PMT 求每期付款
- P/Y、C/Y : 每年付款次数 / 复利次数
- CLR TVM : 清空 TVM 数据
- BGN : 期初(annuity due)/期末(ordinary)年金,END 为默认

**现金流(CF)**
- CF : 输入 CF0、C01、F01、C02、F02…(直接键,同 NPV/IRR)
- NPV : 净现值(给定利率)
- IRR : 内部收益率

**摊销(AMORT)**
- AMORT : 定 P1/P2 期区间 → BAL 余额、PRN 本金、INT 利息

**统计 & 回归**
- DATA : 输入 X/Y 数据
- STAT : x̄、s、σx、Σx、Σx²、Σxy、r、回归斜率/截距
- 回归模型: LIN / LOG / EXP / PWR(统计屏里选)

**日期 / 债券 / 折旧**
- DATE : DBD 两日期间的天数、日期计算
- BOND : 债券价格 / 收益率
- DEPR : 折旧 SL(直线)/ SYD(年数合计)/ DB(余额递减)/ DBX

**利率与换算**
- ICONV : NOM(名义)⇄EFF(实际有效) 利率互转
- Δ% : 百分比变化
- COST / SELL / MARGIN : 成本 / 售价 / 利润率三者换算
- Math : 分数↔小数
- 内存寄存器 : STO→0-9 存, RCL→取;可在任何工作表间复用数值

## 补充

注意命令是可以直接输入在计算界面的。

矩阵用方括号，列表用大括号。

矩阵和列表也可以用表格编辑器。

### ti-basic

以 ti 84 plus 为例,按功能分组。

**输入 / 输出**
- Disp "text" : 显示文本或变量值
- Output(row,col,"text") : 在指定行列显示
- Input "prompt",var : 提示后输入
- Prompt A,B : 依次提示输入多个变量
- Pause : 暂停
- ClrHome : 清屏

**赋值**
- value→var : 给变量赋值
- "string"→Str1 : 存字符串

**控制流**
- If condition / Then / Else / End : 条件分支
- For(I,start,end,step) : 计数循环
- While condition : 当型循环
- Repeat condition : 直到型循环
- Goto label / Lbl label : 跳转
- Stop : 停止
- Return : 返回

**绘图**
- ClrDraw : 清空图形
- Line(x1,y1,x2,y2) : 线段
- Pt-On(x,y) / Pt-Off(x,y) / Pt-Change(x,y) : 点开/关/取反
- Circle(x,y,r) : 圆
- Text(y,x,"text") : 图形上显示文本

**列表**
- {1,2,3}→L1 : 列表赋值
- dim(L1)→N : 列表长度

**其他**
- GetKey→K : 读取按键(配合循环做交互)
- rand / randInt(min,max) : 随机数
